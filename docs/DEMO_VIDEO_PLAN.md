## 1. 촬영 전 준비 체크리스트

### A. 봇·서버 (가장 먼저)
- [ ] **끊김 수정 코드 push → 배포**(`push 해줘` → `배포해줘`). 배포 후 `봇 상태` 에서 connected=true 가 유지되는지 5분 뒤 다시 확인.
- [ ] 촬영 직전에도 `봇 상태` 한 번 더 확인.
- [ ] 시연용 메시지 문구 정하기. 추천: **`@letshwp 이 문서 서식 수정해 주세요`**
  - town-square 에서는 `@letshwp` 멘션이 없으면 봇이 반응하지 않는다.
  - '검사', '테스트', '확인' 단어가 들어가면 **검사 모드**(문서를 바꾸지 않음)가 된다.
  - 띄어쓴 대문자 `A`/`B` 한 글자는 문서 유형으로 해석된다. 넣지 않는다.
- [ ] 채널에 그동안의 테스트 글이 그대로 보인다. 깨끗한 화면을 원하면 ① 봇과 DM(멘션 불필요) 또는 ② 시연용 새 채널을 만들고 봇을 넣기(deploy.json channels 추가 + `join-bot`, 개발 모드 작업 필요).
- [ ] 답장은 **스레드(답글)** 로 온다. Mattermost 설정 '답글 스레드 모으기(Collapsed Reply Threads)' 가 켜져 있으면 채널에는 '답글 2개' 만 보이고 내용은 스레드를 열어야 보인다. 촬영 전에 어느 쪽 화면으로 보여줄지 정해 두기.

### B. 샘플 문서를 열 프로그램
- [ ] 이 Mac 에는 한글이 없다. 선택지:
  1. **한글이 설치된 Windows PC** 에서 촬영(가장 정확한 서식 표시). 그 PC 에도 Tailscale 로그인 + Mattermost 로그인 필요.
  2. 한컴오피스 for Mac 체험판 설치.
  3. 설치된 **Polaris Office** 로 hwpx 열기 — 열리는지, 번호·글꼴이 제대로 보이는지 미리 확인. 한글과 표시가 다를 수 있음.
  4. 한컴독스(웹) — 외부 인터넷·로그인 필요.
- [ ] 수정본을 열어 **'3. 향후 추진계획', '4. 협조 요청사항'** 으로 바뀐 것을 확대해서 보여줄 수 있는지 확인(원본은 1. 2. 4. 5. 로 3이 빠짐).
- [ ] 글꼴(휴먼명조·HY헤드라인M)이 없는 PC 에서는 대체 글꼴로 보인다. 한글이 있는 PC 는 보통 함께 설치되어 있다.

### D. 화면·녹화 (모니터 2개)
- [ ] **녹화는 한 화면만**. 외장 4K(메인)에 한글(또는 뷰어)·브라우저 창을 모두 두고, 맥북 내장 화면에는 대본·이 문서를 둔다.
- [ ] macOS 기본 녹화: `Cmd+Shift+5` → '선택한 디스플레이 녹화' → **외장 모니터 클릭**. 옵션에서 마이크 선택(내레이션 안 하면 '없음'), '마우스 클릭 표시' 켜기.
  - 4K 원본은 용량이 크다. 편집 후 1080p 로 내보내기. 녹화 자체를 1080p 로 하려면 OBS 설치.
- [ ] 외장 모니터는 지금처럼 1920×1080 로 보이는 상태 유지. 브라우저 확대 110~125%, 한글도 화면 배율 키우기.
- [ ] 방해 금지(집중 모드) 켜기, Dock 자동 숨김, 데스크톱 아이콘 정리, 메뉴 막대의 개인 정보(계정 이름 등) 확인.
- [ ] 브라우저: 다른 탭 닫기, 북마크 바 숨기기(`Cmd+Shift+B`), 비밀번호 저장 알림 끄기. Mattermost 사이드바에 다른 팀·채널·DM 이름이 보이므로 민감한 이름이 있으면 가리거나 새 브라우저 프로필로 로그인.
- [ ] Mattermost 알림(소리·배너) 끄기 — 봇 답장이 올 때 알림이 녹화에 들어간다.
- [ ] 마우스 포인터 크게(시스템 설정 → 손쉬운 사용 → 디스플레이 → 포인터 크기).
- [ ] 다운로드 장면: 브라우저 '다운로드 전 저장 위치 묻기' 를 켜 두면 저장 과정을 보여줄 수 있다. Downloads 폴더에 `sample_original_수정본.hwpx` 가 이미 있으면 `(1)` 이 붙으니 미리 치우기. Finder 를 띄울 거면 폴더 안 개인 파일 정리.
- [ ] 봇 처리는 1초 안에 끝난다. '잠시만 기다려 주세요' 와 완료 답장이 거의 동시에 온다. 편집에서 자르지 않아도 된다.
